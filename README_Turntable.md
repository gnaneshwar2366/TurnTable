# Turntable

**Turn the board. Let the balls roll. Drop each one into its own hole.**

A relaxing rotation puzzle for the browser. You never move a ball directly. Instead you turn the whole board a quarter turn left or right, and gravity pulls every ball to the new bottom.

## How to play

- **Turn the board** with the two big buttons, by swiping left or right on the board, or with the left and right arrow keys.
- **Balls roll** to the new bottom until a wall or another ball stops them.
- **Drop each ball** into the hole of its own colour. Balls roll straight over holes of other colours. Each colour also has its own shape mark, so colour is never the only clue.
- **Fewer turns, more stars.** Three stars for matching par, which is the shortest possible solution.
- **Undo, restart and hints are always free.** A hint tells you the next turn and how many remain, and the game warns you when a position can no longer be finished.

## Features

- 120 hand-curated levels in 10 worlds, growing from a 5x5 board with one ball to 8x8 boards with four.
- **Endless levels** after that, generated on your device. Level N is always the same board for everyone.
- **Daily Turn**, a new puzzle each day.
- **Animated tutorial** with four short lessons: a ghost finger shows swipe right, swipe left, chaining turns and matching colours.
- Light and dark themes, sound and vibration that can be switched off, progress saved in the browser.

## How it works

- `engine.js` holds the pure game logic with no DOM: the physics, a breadth-first solver and the level generator. It runs in both the browser and Node.
- Every campaign level was checked by the solver. Par is the proven optimum, and levels are filtered so dead-end positions are rare.
- `gen.js` generates the campaign into `levels.json`. Endless levels use the same rules, seeded from the level number.

## Play

Open `turntable.html` in any browser, on a phone or desktop. It is a single file with no server, no accounts and no install. Fonts load from Google Fonts when online and fall back to system fonts offline. Progress is saved in your browser (`localStorage`).

You can also host it on any static site (GitHub Pages, Netlify, itch.io): upload the file and open it.

## Develop

Rebuild the single playable file from source:

```
node build.js
```

Run the logic tests (Node 18 or newer):

```
node test.js
```

## Project layout

```
engine.js    game rules and logic (no DOM)
ui.js        rendering, input and sound
style.css    layout and light and dark themes
body.html    page markup
build.js     bundles everything into one playable .html
test.js      logic tests
```

Extra files in this game: `gen.js` (level generator, run with `node gen.js`), `levels.json` (generated campaign) and `gen_tut.js` (finds the tutorial levels).

## Limitations

- Built and tested with an automated browser (headless Chromium with touch events) and a solver. It has not been playtested on many real phones, so difficulty and feel may need tuning.
- Sounds are generated in the browser and are simple.
- Endless levels are generated by a program, so some feel easier or harder than their neighbours.
